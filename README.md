# Sherpa — проводник по Escape from Tarkov

Помощник между рейдами: квесты, список «что нести из рейда», барахолка, крафты и интерактивные карты с зонами твоих квестов. Работает **вне игры** — ничего не читает из памяти, не эмулирует ввод, не трогает процесс. Только своё окно и открытые данные [tarkov.dev](https://tarkov.dev).

## Быстрый старт

### Готовый exe (для себя и друзей)

`build-exe.bat` собирает сайт и упаковывает лаунчер в **`release\Sherpa\Sherpa.exe`** плюс архив `release\Sherpa-<версия>.zip` (~18 МБ). Друзьям достаточно распаковать и запустить `Sherpa.exe` — ни Python, ни Node не нужны. **Обновления приходят сами**: Sherpa.exe при запуске и раз в 6 часов смотрит последний релиз на GitHub (`WOLF5ER/sherpa`), в шапке появляется кнопка «Обновление N», в профиле — «Что нового» и «Установить и перезапустить»: архив качается в `%LOCALAPPDATA%\Sherpa\update`, окно закрывается, скрипт подменяет файлы рядом с exe и запускает новую версию; `config.json`, `sherpa.log` и прогресс не трогаются. Выпустить релиз: поднять версию в `package.json` → `build-exe.bat` → закоммитить → `publish.bat` (нужен `gh auth login`; заметки — `release\notes-<версия>.md`, иначе соберутся из коммитов). Нужен Windows 10/11 с WebView2 (в 11 есть всегда; если нет — Sherpa скажет, где скачать). При первом запуске Windows SmartScreen предупредит про неизвестного издателя — «Подробнее → Выполнить в любом случае»: exe не подписан. Рядом с exe появятся `config.json` (хоткеи, LAN, сквад) и `sherpa.log`. Если окно зависло или упало — запусти с переменной окружения `SHERPA_DEBUG=1`: в лог каждые 10 секунд будут писаться стеки потоков и все вызовы API.

### Из исходников

Нужны [Node.js](https://nodejs.org) (для сборки) и [Python 3.10+](https://www.python.org/downloads/) (для окна-оверлея).

```bat
start.bat
```

Скрипт сам поставит `pywebview`, соберёт приложение и откроет окно **Sherpa** поверх всех окон.

- **F10** — показать / скрыть окно
- **F9** — переключить «поверх всех окон»
- **F8** — мини-карта
- **«Ты здесь»**: назначь в игре клавишу Screenshot и жми её в рейде — Тарков пишет координаты и поворот в имя файла в `Документы\Escape from Tarkov\Screenshots`; (если «Документы» у тебя в OneDrive — лаунчер найдёт папку и там; путь виден и меняется в панели «Ты здесь»); Sherpa ставит стрелку с направлением взгляда, ведёт след пути, сама переключает этаж по высоте и двигает карту за тобой. Работает и без лаунчера — в Chrome/Edge кнопкой «Выбрать папку скриншотов» (File System Access API). Читаются только имена файлов, картинки никуда не уходят. Правый клик по карте — своя метка. **Клик по флажку задания** — всплывашка с кнопками «Пункт выполнен» (флажок исчезает, остальные пункты этого задания остаются — удобно для «заложить камеры в трёх местах») и «Задание выполнено»; те же галочки по пунктам есть в списке задач, выполненные пункты импортируются и из TarkovTracker.
- **Цены** — минимальное предложение на последнем скане барахолки tarkov.dev (то, что видно в игре), средняя за 24 ч — в карточке предмета. Сводка обновляется каждые 15 минут, пока приложение открыто; если у tarkov.dev сводка режима застряла — свежие цены подтягиваются по истории для всего, что на экране (барахолка, крафты, «что нести», карточки).
- **Сезонные квесты KORD BREACH** — у tarkov.dev их пока нет, поэтому цепочка (20 квестов: условия, цели, награды, порядок, выбор «Финишная прямая / Последствия наших решений») собрана вручную по tarkov.help в `src/data/seasonTasks.ts` и подмешивается только в режим «Сезон». Точек на карте у них нет. Когда tarkov.dev добавит их — файл удалить.
- **Сквад** — раздел «Сквад» в меню: «Создать комнату» / «Войти по коду», код крупно, приглашение в буфер, участники с картами и давностью, и настройки хоста прямо там — тумблеры «Одна Wi-Fi» (адрес `http://192.168.x.x:4880`) и «Через интернет» (туннель Cloudflare), без правки конфига и перезапуска. Хостом становится лаунчер одного из вас. В одной Wi-Fi — `"lan": true`; через интернет — `"squad_tunnel": true` (`cloudflared.exe` уже лежит в архиве с Sherpa; если его нет — лаунчер сам скачает его один раз с официального релиза Cloudflare в `%LOCALAPPDATA%\Sherpa\bin` и поднимет бесплатный публичный адрес `https://…trycloudflare.com` без аккаунта; адрес виден в «Сквад» и «Профиль → Оверлей»). Хост жмёт «Скопировать приглашение» — это одна ссылка вида `https://…/#/squad?join=код`; друзья вставляют её в «Войти по коду» в своей Sherpa (или просто открывают в браузере — карта с позициями работает и так). Все должны сидеть на одном хосте: если каждый нажмёт «Создать комнату», получатся разные комнаты. В лаунчере войти по голому коду без адреса хоста нельзя — приложение об этом скажет. Позиции друзей — голубые стрелки с никами, обновляются с каждым скриншотом (хост раздаёт всем мгновенно через поток). **Общая карта**: один переключил карту — у всех переключилась (тумблер «Общая карта» в панели сквада; мини-карта следует тоже). **Общие метки**: правый клик по карте в скваде — флажок с твоим ником у всех, клик по нему — убрать у всех, живёт час. Комната живёт, пока запущен лаунчер хоста.
- **Мини-карта** — кнопка «Мини» в шапке или **F8**: маленькое окно без рамки справа сверху поверх игры. Карта по курсу (стрелка всегда вверх), круг или квадрат, след, выходы, зоны доступных квестов, свои метки, друзья из сквада, авто-этаж. Обновляется с каждым скриншотом. По наведению — зум, поворот/север, форма, подписи, выбор карты, закрыть. Перетаскивается мышью. Размер и отступ — `minimap_size`, `minimap_margin` в `config.json`. Совет: повесь клавишу скриншота на боковую кнопку мыши и жми на бегу — или, хитрее, в настройках управления Тарков умеет вешать действие на **отпускание** клавиши: движение вперёд на нажатие `W`, скриншот на отпускание `W` — точка обновляется при каждой остановке, никаких макросов, всё внутри игры. Файлов при этом сотни за рейд, поэтому в `config.json` есть `screenshots_keep` — сколько последних скриншотов оставлять в папке (остальные лаунчер удаляет; трогает только PNG с координатами в имени).
- **Телефон / планшет**: в `launcher/config.json` поставь `"lan": true`, перезапусти — лаунчер напечатает адрес вида `http://192.168.x.x:4879`, открой его на телефоне в той же Wi-Fi: карта, брифинг и «ты здесь» (позиция приходит от лаунчера по сети). Windows может спросить разрешение для брандмауэра.
- **История рейдов** — раздел «Рейды»: след «ты здесь» сохраняется целиком по рейдам (карта, время, путь по скриншотам, пройденное расстояние, у какого выхода закончил). Новый рейд начинается сам после паузы в 20 минут, при смене карты или по «Сбросить след». Исход (выжил / погиб / сбежал) и заметка — руками; по ним считается выживаемость и статистика по картам. «На карте» — повтор пути: бегунок по времени, старт/финиш, стрелка идёт по треку, этаж переключается сам. Живёт в IndexedDB, только локально.
- Таймер дикого в шапке: нажал после смерти на скаве — видишь, когда снова можно.
- В игре поставь режим окна **«Без рамки» (Borderless)** — поверх Fullscreen окно не видно.

Хоткеи и размер окна — в `launcher/config.json`. Хоткеи глобальные: пока запущена Sherpa, F10 и F9 до игры не доходят — если они у тебя заняты в Таркове, поменяй клавиши в конфиге (F1–F24, INSERT, HOME, END, PAUSE, SCROLL).

### Просто в браузере

Если оверлей не нужен (второй монитор, телефон):

```bash
npm install
npm run dev
```

и открой `http://localhost:4879`.

## Разделы

| Раздел | Что делает |
|---|---|
| **Брифинг** | Одна карта — всё для рейда: твои квесты здесь с условиями, ключи и предметы, которые взять с собой, что из нужного может лежать на этой карте, выходы для твоей фракции, боссы, опасности. |
| **Задачи** | Все квесты со статусами «доступно / впереди / выполнено» по уровню, лояльности торговцев и цепочкам. Фильтры по торговцу, карте, Каппе. Отметка «выполнено» тянет за собой предшественников. |
| **Предметы** | Сводный список «что нести из рейда»: агрегация по незавершённым квестам и апгрейдам схрона, FIR-метки, счётчик «есть X из Y», источник каждой единицы. |
| **Ключи** | Справочник ключей и ключ-карт: какие двери на каких картах, каким квестам нужен (с их статусом), «нужен сейчас», число использований, цена и где дешевле, цена за использование, бартеры, точки спавна. Галочка «есть» — ключ в схроне. |
| **Схрон** | Планировщик: следующий уровень каждой станции, стоимость по текущим ценам, время, бонусы, что блокирует; «Построено» поднимает уровень в профиле. |
| **Барахолка** | Цены за 24 ч, лучшее место продажи с честной комиссией рынка, цена за слот, «растут в цене», «выгоднее торговцу». Список слежения (звезда) с порогами «ниже / выше». |
| **Крафты** | Прибыль и прибыль/час крафтов и бартеров с учётом твоих станций и уровней торговцев. |
| **Патроны** | Таблица патронов по калибрам: урон, пробитие (цвет — какой класс брони берёт), урон по броне, фрагментация, цена и где купить. Вкладка «Броня»: класс, прочность, материал, штрафы. |
| **Сборка** | Оружейный конструктор: дерево слотов из данных игры, стандартные пресеты, эргономика/отдача/вес/цена как в игре (сверено со стандартным пресетом M4A1), совместимость и конфликты модулей, автоподбор под эргономику / отдачу / баланс / цену с бюджетом и «только доступное мне», патроны под калибр, сохранённые сборки. |
| **Навыки** | Все 35 навыков по вики: что дают за уровень и на элите, чем качаются (только обычными действиями в игре), советы, общие правила прокачки и ускорители схрона. Свой уровень вводится вручную — подсвечивает требования схрона и квестов и квесты, дающие уровни наградой. |
| **Карты** | Тайлы и SVG-карты tarkov.dev, выходы с условиями (ракета, кооп, платный, записка, рычаг, без рюкзака — сверено с вики, `src/data/extractRules.ts`), транзиты, спавны, боссы с шансом, двери с ключами (и ценой), мины, БТР, этажи. **Зоны твоих активных квестов** прямо на карте. «Где лежит» — точки россыпного лута для предмета. |
| **Рейды** | История рейдов по скриншотам: карта, длительность, путь, выход, исход и заметка; выживаемость и статистика по картам; повтор пути на карте с бегунком по времени. |
| **Сезон** | Несколько персонажей (основной / сезонный) с раздельным прогрессом, сезонные модификаторы (пока — «неработающая барахолка»: все расчёты идут через торговцев), сезонные достижения с отметками, сезонные спавны и квесты с сезонными противниками. |
| **Профиль** | Уровень, фракция, режим PvP / Сезон / PvE (у каждого своя лента цен tarkov.dev: `regular`, `pvp-season`, `pve`), уровни станций схрона, ручные уровни торговцев, экспорт/импорт прогресса. |

`Ctrl+K` — глобальный поиск по предметам, квестам и картам, понимает неверную раскладку («дувч» → LEDX). Кнопка солнца/луны в шапке — светлая тема («бумага и латунь»); карта остаётся тёмной, тайлы нарисованы под неё. `?theme=light` в адресе — принудительно.

## Откуда взять свой прогресс

Из самой игры прогресс не вытащить — у BSG нет открытого API, а лезть в память или логи Sherpa принципиально не будет. Варианты:

1. **Отметить руками.** В «Задачах» галочка на квесте закрывает и всех его предшественников — прогресс в сотню квестов набивается за десяток кликов по «концам» цепочек. Уровень и схрон — в профиле.
2. **Импорт из [TarkovTracker](https://tarkovtracker.org).** Если ведёшь прогресс там — создай в настройках API-токен (для сезонного персонажа он начинается с `SZN_`, для обычного — `PVP_` / `PVE_`), вставь в «Профиль → Импорт из TarkovTracker». Подтянутся уровень, фракция, выполненные квесты и уровни схрона. Запрос идёт через локальный прокси лаунчера или dev-сервера — их API не открыт для браузеров напрямую.
3. **Экспорт / импорт файла Sherpa** — резервная копия и перенос между браузером, лаунчером и компьютерами.

## Данные

Справочник берётся со статического зеркала `json.tarkov.dev` (им пользуется сам сайт tarkov.dev), парсится и собирается в Web Worker (интерфейс не замирает), кэшируется в IndexedDB, цены обновляются каждые 15 минут. Режимов три — `regular` (PvP), `pvp-season` (сезонный персонаж) и `pve` — с разными ценами барахолки. Если сводный файл режима вдруг устаревает (tarkov.dev так уже бывало), Sherpa подтягивает свежие цены по истории `…/prices/<item>` для того, что открыто на экране, и помечает это в карточке. Прогресс хранится только локально (localStorage) — в лаунчере это `%LOCALAPPDATA%\Sherpa`, в браузере — профиль браузера.

Карты и иконки — © авторы из [the-hideout/tarkov-dev](https://github.com/the-hideout/tarkov-dev) (MIT); Sherpa лишь отображает их.

## Стек

Vite · React 19 · TypeScript · Tailwind v4 · Zustand · Leaflet · pywebview (окно WebView2).

```
src/
  data/       загрузка и нормализация tarkov.dev, метаданные карт
  lib/        расчёты: статусы квестов, агрегация предметов, комиссия рынка, поиск
  store/      профиль игрока, данные, UI
  pages/      Брифинг · Задачи · Предметы · Ключи · Схрон · Барахолка · Крафты · Патроны · Сборка · Навыки · Карты · Рейды · Сквад · Сезон · Профиль
  components/ оболочка, карточка предмета, поиск, ячейка схрона
launcher/     sherpa.py — окно-оверлей, хоткеи, прокси, сквад, автообновление; sherpa.spec — сборка exe
publish.bat   релиз на GitHub (zip из release/) — Sherpa.exe у друзей увидит его сама
```

## Известные ограничения

- Квесты в 1.0 частично открываются «сюжетным прогрессом» торговца, которого нет в открытых данных, — такие квесты показываются как доступные при подходящем уровне (как и в вики).
- Сезонный контент (квесты, предметы, спавны) приходит из данных автоматически; модификаторы сезонного персонажа приложению неизвестны — отмечаются вручную в разделе «Сезон».
- Выходы: у tarkov.dev нет части выходов (например, Reserve D-2, Woods «Мост дружбы», половина Маяка) — они показаны в брифинге по вики без координат. На Таможне в данных все выходы ссылаются на один рубильник — это артефакт, он отфильтрован.
- Репутация торговцев не учитывается: уровень лояльности считается от уровня ЧВК, но его можно задать вручную в профиле.
- Уровни навыков игра наружу не отдаёт — в «Навыках» они вводятся руками. Карта рейда в истории берётся из той, что открыта в приложении; если карту не открывали — рейд помечен «Какая карта?» и её можно выбрать в списке.
